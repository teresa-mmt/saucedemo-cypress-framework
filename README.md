# Sauce Demo Cypress Automation Framework

## Project Overview

This project automates the end-to-end testing of Sauce Demo e-commerce workflow using Cypress.

Core Business Flow:

Login
→ Inventory
→ Cart
→ Checkout Information
→ Checkout Overview
→ Order Completion
→ Navigation & State Management

---

## Modules Covered

- Login
- Inventory
- Cart
- Checkout
- Navigation & State Management

---

## Tech Stack

- Cypress
- JavaScript
- Mocha
- Chai

---

## Test Types Covered

- Smoke Testing
- Functional Testing
- Regression Testing
- Negative Testing
- E2E Testing
- Resilience Testing

## Project Goal

Validate critical retail workflows and ensure stable checkout behavior using production-ready QA automation practices.
